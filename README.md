Sistema de Gestão de Doações Comunitárias

Projeto acadêmico desenvolvido para auxiliar no cadastro, controle e acompanhamento de doações comunitárias da Associação Comunitária Esperança.

Funcionalidades
Cadastro de doadores
Cadastro de doações
Registro dos itens doados
Controle da quantidade de itens
Cadastro de beneficiários
Validação de campos obrigatórios
Interface responsiva


Tecnologias utilizadas
HTML5
CSS3
Git
GitHub
Visual Studio Code


Como executar o projeto
Faça o download ou clone este repositório.
Abra a pasta do projeto no Visual Studio Code.
Abra o arquivo index.html.
Execute o arquivo no navegador.
Utilize o formulário para realizar o cadastro das doações.


Objetivo
O sistema foi desenvolvido como um MVP para facilitar a organização das doações recebidas pela Associação Comunitária Esperança, permitindo registrar informações de doadores, itens, quantidades e beneficiários.
