Sistema de Gestão de Doações Comunitárias

Projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas.

Objetivo
Desenvolver um MVP para auxiliar no gerenciamento de doações comunitárias, permitindo o registro e acompanhamento de doações, doadores e beneficiários.
